# Lofi

「集中するほど、帰ってきたくなる場所が育つ。」

SwiftUI / iOS 17以降。黒を基調に、屋上・神社・貝殻・火種の工房それぞれの5段階のGIFを使用する作業用アプリです。貝殻の世界の作業画面は白い背景に合わせた表示です。

## 起動

採用GIF・画像・音源はGit LFSで管理しています。初回はGit LFSをインストールし、クローン後に `git lfs install` と `git lfs pull` を実行してください。アプリが使用する完成素材はすべて `Lofi/Resources/` に同梱しています。`output/` の試作メディアやビルド・署名ファイルはGit管理対象外です。制作プロンプト・マニフェストと、現在の工房アニメーションを再生成するための元画像は含めています。過去の制作スクリプトにはローカル保管の試作素材を参照するものがあります。

`Lofi.xcodeproj` をXcodeで開き、LofiスキームでiPhoneシミュレータに実行してください。実機ではSigning & CapabilitiesのTeamを指定します。

XcodeGenを使っているため、プロジェクト設定を変更した場合は以下で再生成できます。

```sh
xcodegen generate
xcodebuild -project Lofi.xcodeproj -scheme Lofi -sdk iphonesimulator -derivedDataPath build/DerivedData CODE_SIGNING_ALLOWED=NO build
```

## 実装した体験

- 作業・コレクション・設定の3タブ。
- GIFは最初から全体が収まる表示。ピンチで最大4倍に拡大でき、拡大中は画像が画面からはみ出す範囲でドラッグできます。横向きにも対応します。
- 背景タップでUIを表示・非表示。時間経過では自動で隠れません。
- 開始ボタンをタップすると、上方のアーチに「計測・ポモドーロ・タイマー」の3つを表示。各ボタンのタップ、または開始ボタンを長押しして目的のモードへスライドし、指を離す操作に対応します。
- 計測は時間設定なしのストップウォッチ。ポモドーロは作業・短い休憩・長い休憩を分単位で設定し、4回ごとに長い休憩を挟みます。タイマーは1分〜11時間59分とプリセットから選択できます。設定は次回に引き継ぎます。
- 全モードで一時停止・再開・終了。バックグラウンドや再起動を挟んだ時間も日時から復元します。ポモドーロの休憩は記録・育成から除外。タイマーは指定時間で計測を打ち切り、既存の確認設定に従って終了します。
- 区切りでは前面表示中にチャイムと触覚で通知。通知を許可すればバックグラウンドでも通知します。アプリを開いたときや一時停止・再開時に予定を更新し、終了時に取り消します。
- 作業画面は参考画像に合わせ、時間と操作を分けた配置です。タイトル・X/5・進化ゲージは左上、作業中の経過時間は上部中央に大きく表示します。下部には丸い一時停止／再開ボタンと終了ボタンを並べます。作業前は同じ場所に丸い開始ボタンを表示し、モード選択へ進みます。作業画面のタブは囲いをなくし、選択中のタブに細い下線を表示します。
- 左上にタイトル・X/5・次の進化までのゲージを配置。作業中の時間を仮表示し、終了時の確認後に確定します。
- 確認頻度は「なし・軽め・毎回・こまめ」。軽めは60分以上の終了時、こまめは指定間隔でアプリ表示中にも確認します。
- 作業していなかった時間の控除・記録の破棄。確定した時間だけを記録と育成に同じ値で反映します。
- 記録と育成は端末内のApplication SupportへJSONで保存します。
- 解放された段階だけをコレクションで閲覧・作業背景に設定できます。未解放の絵と音の名前は伏せます。
- 屋上のコレクション詳細から「物語を読む」で『夜にちょうどいい広告』を開けます。選んでいたランクの話から始まり、確定済みの育成ランクまで各話を切り替えられます。未解禁の章タイトル・本文は表示しません。物語のないサンプルには読書ボタンを表示しません。
- 読書画面はC案の、景色を背景に透かす構成です。読んでいる章と同じランクのGIFに薄い暗幕を重ね、明朝体の本文と下部の丸い章選択を表示します。章変更時は背景をクロスフェードし、詳細のプレビュー・音も同じランクに合わせます。読書中は詳細側のGIFを一時停止します。長い本文や横向きでは本文部分をスクロールでき、閉じる・章選択は固定です。
- 読書背景のGIFは30％の濃度で表示します。全体タイトルは「物語」の固定ヘッダー、各話のタイトルは「第○話」のバッジと区切り線付きの見出しにし、本文と区別します。下部の1〜5はコレクション詳細と同じ部品を横向きに使い、つないだ丸の上を小さなつまみが移動します。数字のタップ・横ドラッグに対応し、未解禁ランクへの移動はできません。
- コレクション詳細はスクロールせず、画面の高さに応じてプレビューを縮小して操作部を収めます。横向きはプレビューと操作部を左右に配置します。「育成中の風景に戻す」は廃止し、最新ランクを選んで作業すると以後の進化に追従します。過去ランクはその風景に固定できます。
- 詳細でランクを切り替えると、プレビューは0.8秒のクロスフェードで切り替わります。GIFの再生を継続し、デコーダーとキャッシュは1組を使います。「視差効果を減らす」が有効な場合は即時に切り替えます。
- 詳細のランク1〜5はプレビュー左の丸い目盛りを一本の線でつなぎ、重なる小さな円形のつまみを上下にドラッグ、または数字をタップして切り替えます。未解禁ランクには移動できません。タイトルには下線を付け、重複するX/5・完成／育成中の説明は省いています。閲覧中は選択したランクの音を再生し、タイトル横の音響ボタンからBGM・環境音を調整できます。作業背景のランクは変更せず、詳細を閉じると作業背景の音へ戻ります。BGMのオン・オフと音量の設定は尊重します。デバッグ用サンプルは専用音源がないため共通BGMのみを使用します。
- 音は従来の仮音源を独立して再生します。背景の特定箇所をタップして音を切り替える機能は廃止し、右中央の曲名・スペクトラムをタップして開く音響設定から操作します。音のオフでもアニメーションは続きます。
- 右中央に曲名「Night Signal」と、曲名に重なる透過度の高い白色の半円オーディオスペクトラム（円の中心を画面右端に置き、左半分を表示）を配置。BGM再生中はBGMだけを48帯域で分析します。BGMオフ時は環境音・通知チャイムのPCMを、それぞれの再生位置と音量で合成して分析。全音源停止時は静止します。バックグラウンドやパネル非表示中は解析を止めます。
- 「この場所の音」は暗いすりガラスのシート。作業画面とコレクションの両方で背面をネイティブのMaterialでぼかします。Material自体の不透明度を12％、青灰色の重ねを4％に抑え、背景が直接透けるようにしています。BGMと4つの環境音を横スライダー・11本の目盛り・音量％で表示し、音のアイコンでオン・オフ、BGMには再生／停止ボタンを用意しています。ミュート中は0％表示、再開時には保存済み音量に復帰します。未解禁の名前を隠し、音量調整も無効化します。「透明度を下げる」設定時は不透明な背景に切り替えます。
- 解禁済みの音はオフでもスライダーを操作できます。0より上へ動かすと、その音をオンにして音量を反映します。未解禁の音は操作できません。ミュート解除・音声出力への反映・音量保存・未解禁制限の回帰確認を追加し、コア検証はDebug 37項目・通常版28項目が通過しています。
- コレクションと設定の見出しは日本語のページタイトルのみ。コレクションはiPhoneでは2列のポスター一覧で、画像とタイトル・X/5を表示します。iPadでは画面幅に合わせて列数を増やします。実際の風景と書斎サンプルはGIFを再生し、その他の候補画像サンプルは静止画です。詳細画面では選んだ風景を表示します。
- GIFはImageIOで必要なフレームだけデコードし、キャッシュを制限しています。アプリが背景に入るとアニメーションを止めます。

## 現在の内容と仮設定

屋上「ネオンの向こうの屋上」と神社「幾重の社」を実装しています。それぞれランク1から、25分の確定した作業ごとに進化し、100分でランク5になります。屋上は438×900、神社は600×1300の比率を各画面で使用します。コレクション詳細の「この世界で作業する」で切り替えられます。作業中は別の世界への切り替えを無効にし、記録の加算先は開始時の世界に固定します。各世界の育成時間・表示ランク・音量設定は独立して保存し、従来の屋上の育成時間と記録を保持します。

神社の物語『もうひとつだけ』は「ひとつだけ／小さな申請／通るところ／入口もひとつ／帳面の続き」の5話で、各ランクまでの絵に沿って解禁します。最後は「全部でいくつですか」。読書背景と終了時の続きボタンも対象世界に対応し、屋上側の進捗によって神社の章が解禁されることはありません。ランク5は天狗・石段の歩行狐を追加する前の枝ではなく、それらを除いた最終v6を採用しています。

神社の音はBGMに加えて、水音（1）・筆音（2）・葉擦れ（3）・鈴（4）・鳥の声（5）。雨・暖炉・キーボード音は使いません。追加の環境音は `scripts/generate_shrine_audio.py` で生成した仮の合成音で、製品向け音源への差し替えを想定しています。神社のGIFは計約347MBのため、今後の配信サイズ最適化は別途必要です。完成した動き・画質・ループ時間は変更していません。

2,400フレームのGIFはメタデータの走査もバックグラウンドで行い、読み込み完了後に既存の0.8秒クロスフェードへ渡します。切り替え中の古い読み込みはキャンセルし、キャッシュの16MB制限は維持しています。

音は `scripts/generate_audio.py` で生成したオリジナルの合成音です。実際に再生できますが、製品向けのBGM・環境音への差し替えを想定しています。GIFには音が入っていないため、AVAudioPlayerで独立して重ねています。

定期確認はアプリが前面にあるときに表示します。画面を消している間のプッシュ通知・作業アプリの利用監視・サーバー同期・課金は未実装です。

## 検証

アプリ本体はiOS Simulator向けにビルド・起動確認済みです。屋上シーン採用後、iPhone 16 Pro / iOS 18.4シミュレータで作業画面・コレクション・全5ランクの切り替えを確認しています。同梱した各GIFと採用元のSHA-256が一致し、ImageIOで全ランクの寸法・フレーム数・ループ時間を確認しました。デバッグ版のコア検証20項目も通過しています。

2026-11-23、iPhone 13 / iOS 26.6.1へ最新Debugビルドを上書きインストールし、起動を確認しました。ランク5プレビューで60秒以上経過した後も同一PIDが稼働し、監視中の自発的終了はありませんでした。最後にプレビュー引数なしで通常起動へ戻しました。実機の画面操作・各演出の見た目はこの確認には含めません。

実機向けの未署名ビルドを手動署名する場合は、`scripts/sign_device.py APP --profile PROFILE --identity IDENTITY` を使います。Xcodeの `Lofi.debug.dylib` と `__preview.dylib` も先に署名し、各ライブラリを個別に検証してからアプリを署名します。アプリ本体だけの署名では、実機で `DYLD / missing code signature` により起動直後に終了します。

`LofiTests` にXCTestを用意しています。2026-11-25の神社統合時にiPhone 16 Pro / iOS 18.4で実行し、既存と神社の8件に加え、長いGIFの非同期読み込み・連続切り替えの追加1件が通過しました。
